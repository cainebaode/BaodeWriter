本目录维护饱得写作的编辑界面、原生外壳、测试与打包。产品背景、官网和内部资料入口见 [项目总览](../README.md)。

所有 npm 与原生构建命令在本目录执行。以下为使用及构建说明，也用于安装包随附文档。

## 外观与阅读

采用连续深色文稿栏、浅色正文与居中的全局搜索。设置 → 外观提供石墨、深绿、暗酒红、深蓝四套配色，并可独立选择浅色、深色或跟随系统；偏好会自动保留。设置 → 编辑与阅读可调整中文字体、字号、行距和正文宽度。切换外观不重载编辑器，不改文稿和网站格式。

设置按外观、编辑与阅读、AI 服务、网站连接、数据与恢复、关于分类；已有 AI 配置先展示列表，选择后编辑，保存操作保留在底部。

## 安装与开始写作

macOS 13 或更新版本，支持 Apple Silicon 和 Intel。本地迭代安装包为 `dist/BaodeWriter-0.10.1-universal.dmg`，将「饱得写作」拖入 Applications。采用本地签名，尚未经过 Apple 公证；官网安装包另行发布。

1. 点击「＋ 新建」或 ⌘N，直接写标题和正文。看到「已保存到本机」后即可关闭；断网不影响写作。
2. 正文输入 `/` 插入标题、列表、表格或图片；也可粘贴图片。旧 Markdown 文稿保留源码编辑，可切换预览。
3. 系统菜单「文稿 → 文稿设置」中管理标签、封面、摘要和发布日期。发布日期决定网站展示；自动创建、修改时间独立记录。已发布文章地址保持不变。
4. 「连接网站」默认 `https://baode.life`，点击登录，用网站现有管理员账号登录。应用向网站确认成功后自动返回写作，侧栏显示网站域名与连接状态；再次点击可查看连接状态、读取文章或返回写作。会话失效时重新登录，断网时可继续写作。
5. 「读取网站」选择已有文章导入本机。本站图片一并下载；遇到外部图片或下载失败会显示提示，联网时可重新读取。
6. 打开单篇或勾选多篇，点击「同步到网站」，确认后文章和图片一起公开，网站自动更新。其余文稿留在本机。

「专注」隐藏整理区域；侧栏支持标题和正文搜索、标签筛选、发布日期或修改时间排序。「归档」只整理本机，不撤下网站文章。

## 文稿树与文章目录

采用已选「墨灰亚麻」配色，保留窄导航、圆角面板和暖白纸面；新建、选中文稿与 AI 入口使用暖灰陶土红。品牌标识直接使用官网矢量 Logo。系统顶部工具栏保留红黄绿，右侧并排放置哑光搜索与专注按钮；点击搜索或 ⌘F 在同一行向左展开输入框，Esc 收起并保留查询。同色背景自然衔接内容区；标签筛选位于文件列表顶部，侧栏操作与文稿标签页对齐。左侧导航的书页图标打开文稿树；其下方的双箭头图标打开整体网站同步管理，不必先展开文稿栏。文件列表顶部的图钉可将它固定，选择文稿后继续常驻。再次点击图钉取消固定，选择文稿或点击外围后收起。固定偏好会在下次启动时恢复。

文稿栏展开、点外部收起、选择文稿或 Esc 关闭都带有完整进出过渡；固定与取消固定时正文同步让位。目录、AI、文稿设置、菜单与弹窗沿用同一套动效，快速反向操作会从当前位置接续。Esc 优先关闭当前浮层；AI 收起后保留未发送的输入。拖动调宽直接跟随鼠标，系统减少动态效果时停用过渡。

文稿树中，文件夹使用更醒目的名称和展开／收起图标，文章使用较轻的文稿图标；层级之间用连续引导线和统一缩进连接，当前文稿的上级路径以暖色标示。未分类文稿在独立分区显示。每篇标题下以较小字号显示博客发布日期；未发布文稿标注「待发布」与计划日期，日期与文稿设置一致。点击名称打开文稿；左侧小箭头只展开、折叠子文稿。文稿本身可以写正文，也可以拥有子文稿。行内「＋」在该文稿下新建子文稿；顶部「＋」和 ⌘N 新建顶层文稿。新建后直接输入标题。

行内「···」或右键菜单提供重命名、移动和删除。拖动时会出现跟随鼠标的标题预览和目标提示：行中部高亮表示移入，行上／下方蓝线表示插入排序，拖到拖动时出现的「移到文稿顶层」区域回到顶层。文件夹可在同级之间拖动排序，拖到行中部移入目标文件夹；悬停片刻展开目标分支，靠近边缘自动滚动。Esc 或在无效位置松手取消移动；成功后新位置短暂高亮。也可用「移动到…」明确选择位置。移动父文稿时子文稿一起移动，不能移入自身或后代。文件夹按父子层级显示，分组下同时显示子文件夹和直属文稿。「文稿」旁的更多菜单可新建文件夹、批量选择或展开／折叠全部。文件夹菜单可新建子文件夹；「管理文件夹」可更名和调整上级。文件夹可拖入其他文件夹或移到顶层，子文件夹和其中的文稿一并保留，不能移入自身或后代。删除文件夹时，直属文稿和子文件夹移到它的上一级。

搜索覆盖标题、正文、标签与日期，结果显示所属路径，可直接打开文稿。文稿栏顶部的标签图标支持独立筛选；范围与排序在「文稿 → ··· → 范围与排序」中。正文上方保留完整路径的悬停提示。归档或删除父文稿不会隐藏仍正常使用的子文稿。

系统「文稿」菜单提供文稿设置、阅读预览、移动和移到废纸篓。写作区顶部保留 AI 入口，目录从正文顶部目录按钮展开。

「目录」是当前文稿的标题大纲，与文稿树分别显示。它按照正文标题层级缩进、长标题省略、当前章节以主题浅色块突出；点击跳到正文对应位置。Markdown 原文定位光标，预览定位标题。目录默认收起，点击正文顶部目录按钮展开／收起；没有额外的目录标题栏。目录与 AI 助手可以同时使用。

文稿栏通过左侧导航按钮展开／收起。固定后的文稿栏、目录和 AI 栏可以拖动边缘调宽；双击恢复默认。窄窗口进行分栏或使用 AI 时，文稿树临时改为浮层；窄窗口分栏中的目录同样由正文顶部目录按钮打开。窗口加宽后恢复固定栏位。专注模式暂时隐藏导航与侧栏。

父子关系、文件夹随文稿备份；展开状态与栏位偏好只记在本机。整理不改变正文、网站发布内容或同步状态。

## 文稿标签与左右对照

点击列表文稿会保留一个标签；再次点击同一篇只切换到已有标签。标签根据标题收紧宽度，长标题省略，打开较多时横向滚动；关闭按钮紧邻标题，仅在当前、悬停或键盘聚焦时显示。关闭标签保留本机文稿。标签和分栏状态会在下次启动时恢复。

打开至少两篇后，点击标签栏右侧「分栏对照」，选择放在右侧的文稿。最多同时显示两篇，两边都可编辑、独立滚动和预览。点击哪一侧，目录、文稿设置、AI 与同步按钮就对应哪一篇；面板顶部主题浅色标题块标示当前编辑位置。

分栏时选择第三个标签，会替换当前操作的一侧，另一侧保持原样。「结束分栏」保留当前编辑的文稿，其他标签仍可切换。窄窗口会暂时收起整理栏，为两篇正文留出空间；退出分栏后恢复。

正文有序列表按父级路径显示编号，例如 `1.`、`1.1.`、`1.1.1.`，支持更深层级、插入和缩进后重新编号。富文本编辑和阅读预览、Markdown 阅读预览使用同一规则；原始正文格式保持兼容。

## 网站同步管理

文稿栏底部的「网站同步」集中管理整体同步情况；打开时该项高亮。文件夹菜单中的「管理此文件夹同步」直接限定当前文件夹，包含所有子文件夹。可按状态筛选、勾选单篇或批量选择待上传文稿，再确认同步。

管理页区分仅在本机、待同步、已同步、网站草稿、网站有变化、版本冲突、同步失败和关联其他网站。打开管理页或点击「检查网站状态」只读取网站最新版本。失败可按篇重试；网站有变化时先比较并保留双方版本。归档文稿需先恢复；废纸篓不出现在文稿树、已打开标签、同步管理或网站导入选择中。

文件夹结构用于本机整理和批量同步范围，不在网站创建同名目录。所有文章与图片上传仍需明确确认；移到废纸篓不撤下网站文章。

## 删除与恢复

打开文稿后点击系统菜单「文稿 → 移到废纸篓」，确认后移到废纸篓；也可在列表勾选多篇后一起删除。删除会关闭对应标签，其他文稿与分栏内容保留。标签上的 × 仍只关闭视图。

左下角「设置 → 数据与恢复 → 废纸篓」可以恢复文稿，原文、图片、记录日期和文件夹归属一并保留。确实不再需要时，点击「彻底删除…」并确认，从当前本机文稿库移除正文及对应 AI 记录。废纸篓内容随文稿备份保存。

以上操作只影响本机，网站上的文章不会被删除或撤下。重新读取网站时不列出仍在废纸篓中的文稿；需要时请先恢复。

## 参考资料与批注写作

左侧「参考资料」可收存网页、公众号正文、Markdown 与配图，也可从本机文稿建立阅读快照。输入公众号链接并点击「读取链接」，应用会打开独立网页；如微信要求验证，在该窗口完成，正文出现后会自动回到收存预览，无须复制粘贴。普通网页优先直接提取，失败后打开同一读取窗；也可点「在应用内打开」查看原网页并读取当前文章。取消读取保留表单原有内容，验证页和文章不可用页面不会被当成公众号正文。

预览确认后再「收存到本机」；收存时尝试保存配图，失败的地址仍保留并提示。读取窗使用独立临时网页会话，与网站登录、文稿和 AI 密钥分开；关闭应用后不保留该会话。资料默认只读，更新保存为新版本，作者、标题与原链接随版本保留。资料归档后，已有引用仍可阅读。

在原文选中一句或一段，点击「高亮并添加批注」；「整篇想法」用于不挂选段的笔记。批注自动保存到本机，勾选后可加入当前文章，或「用所选批注新建文章」。新文章保留材料关联，正文从空白开始。

正文顶部「材料」打开本篇写作材料。摘录与批注直接可读，「展开上下文」在原处显示前后文，「全文对照」在旁边连续阅读；正文保留原选区。点击「附到正在写的段落」后，富文本正文在该段下方显示内部参考；Markdown 编辑保持源码，段内参考在阅读视图显示。段落位置失效时，材料仍保留，可重新附到段落。窄窗口中材料在底部抽屉显示，正文上方保留编辑区域。

材料区与 AI 的范围分别管理。在助手的「本轮材料」中选择摘录及前后各一段，或选择全文，再发送问题；「预览实际发送内容与历史」可阅读本轮正文、作者原稿、材料与批注。历史可能含旧资料，需要排除时勾选「本轮不带历史对话」。图片地址不代表模型读取了图片内容。

AI 回复的依据可直接展开阅读；补读内容会标明该轮未发送，历史回复保留当时快照。模型提供有效原文位置与可唯一定位的生成段落时，接受后会保留段落参考；无法唯一定位则保留在材料区供手动附上。讨论可明确保存为带来源标记的「AI 笔记」。

本篇采用的批注版本默认只读。「编辑原批注」保存来源记录后，需另点「更新本篇采用版本」才更新本篇；其他文章与历史对话保持各自版本。内部参考不进入复制正文、字数、网站同步或发布；「插入原文引文」才把摘录及可公开出处写入正文，改动后会提示与原文有差异。资料、版本、批注和关联随文稿备份保存。

## AI 写作助手

顶部「写作助手」打开聊天面板。可以直接说“把这些想法写成一篇随笔”“展开第二节”“接着写”“再朴素一点”，也可先讨论观点。四个常用入口是写完整文章、重写全文、梳理结构和生成提纲；通篇优化与标题建议在更多菜单。

助手围绕当前文章工作，逐步记录你明确给出的主题、读者、立场、篇幅和语言偏好。输入框上方的「本篇写作约定」默认折叠，可随时编辑或清空；新对话保留约定，另存生成稿时带入新文稿。不必先填表，材料足够时直接写。

**讨论留在聊天，生成内容在正文区审阅。** 写整篇会生成标题与正文；修改某段、某节只替换相应范围；续写、例子或提纲可插在指定位置。查看修改对比或「新版预览」后接受，内容成为可编辑的原生标题、段落、列表等。局部修改保持其余原文与格式；Markdown 文稿继续保持 Markdown。无需复制并清理聊天说明。

选中文字后点击「AI 润色」，可直接提出修改或扩写要求。只改选区内文字，同时参考所在内容块及前后各两块；完整选中的段落可替换为多个新段落，部分选区只能文字微调或在所在块后补充。取消引用旁的 × 回到全文。独立构思从「··· → 独立构思」开始，不读取当前文稿。

上一稿还未接受时可以继续修改，助手以最新待审阅稿为依据。接受才写入正文；关闭审阅、继续追问或拒绝均不会改原文。原文有新变化时不能用旧提案覆盖。聊天中的卡片可以重新打开建议。

「··· → 修改记录与恢复」可撤销已接受的修改，或恢复为新文稿。章节替换、插入和整篇生成整体接受；文字微调可以逐处接受。图片、链接与代码遗漏会阻止覆盖，建议仍可另存或要求补齐。另存生成稿保持文档格式并保留写作约定。

在「应用设置 → AI 服务」或助手配置旁的「管理」中，可以新增、编辑和移除多套 AI 配置。每套独立保存名称、服务商、接口、模型及密钥；同一服务商也可以配置不同模型或账户。填写自己的 API Key 与已开通模型，保存并测试连接。提供 26 个服务商及平台预设，按国内、海外、聚合与云平台分组，包括 DeepSeek、通义千问、豆包、Kimi、智谱、MiniMax、百度千帆、腾讯混元、讯飞星火、阶跃星辰、百川、OpenAI、Claude、Gemini、Grok、Mistral、Cohere、Perplexity、Azure OpenAI、腾讯 TokenHub、硅基流动、魔搭、OpenRouter、Groq、Together AI 和 Fireworks AI，另保留自定义兼容接口。新增预设的模型名称按账户已开通的模型填写，地域或资源专用地址按提示调整；各项附官方文档入口。密钥保存于 macOS 钥匙串，文稿备份不包含密钥；连接测试不发送文稿。

助手顶部的「AI 配置」下拉框可直接切换配置，并记住上次选择。切换保留聊天、未发送的输入、写作约定和待审阅建议；不会自行发送内容。后续发送使用所选配置及当前会话的必要上下文，每条回复标出当时使用的配置和模型。生成过程中请先停止，再切换。移除当前配置后会使用剩余配置；若已全部移除，助手会提示重新添加。

会话、写作约定与修改记录保存在本机，随内容备份保存。发送时引用内容与必要历史交给选定服务；长文或会话超限会明确提示新对话或缩小选段。助手不自动联网检索或扫描文稿库；明确选择的参考资料会按本轮范围发送，其他事实材料与风格范例可在聊天中提供；生成内容仍需作者判断。未配置服务、断网或调用失败不影响本地写作。

## 同步失败或出现冲突

失败不会丢失本机文稿。恢复网络或重新登录后再次同步即可；相同文稿重复同步不会产生另一篇文章。

两端都发生变化时会显示双方版本，不自动覆盖。「采用网站版」会另存原本机内容；「保留本机版」会另存网站内容，再由你点击同步。若文章在网站被删除，先另存本机副本，按新文章发布。网站原文章的撤下与回收仍使用现有后台。

## 备份与恢复

点击左下角「应用设置 → 导出备份」，选择保存位置，得到 `.baodewriter` 文件夹，包含可读的文稿 JSON、图片和格式清单。复制整个文件夹即可备份；可再用 Finder 压缩归档。请保留整个文件夹，不单独移动其中的图片。

在「应用设置 → 帮助与恢复备份」选择备份文件夹。恢复替换当前本机文稿库，应用先保留恢复前副本；网站不会因恢复而改变。原始数据在 `~/Library/Application Support/BaodeWriter/`，自动保留上一份有效文稿文件；这不能代替独立备份。

## 从源码构建

安装 Apple Command Line Tools 和 Node.js 20 或更新版本。在当前 `app/` 目录执行：

```sh
npm ci
npm run build
```

构建依次检查类型、模型行为、前端、实际打包依赖许可证、原生存储测试，再生成 universal App 与 DMG。构建首次需要联网获取 npm 依赖和已锁定的开源源码归档。测试不会连接正式网站；原生验证命令详见 `native/README.md`。

- `web/`：写作、整理、版本冲突与手动同步界面。
- `native/`：系统窗口、本机存储、图片、登录、备份和网络桥接。
- `tests/`：正文、图片引用、日期与版本比较测试。
- `scripts/`：构建、图标、许可证归集；`package-lock.json` 固定依赖。
- 官网位于同级 [site/](../site/README.md)；网站服务端在 BaodeLife 项目维护。
