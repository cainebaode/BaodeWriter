# 饱得写作

独立 macOS 本地写作应用。正文、图片和编辑记录保存在本机；只有选择文稿并点击「同步到网站」才发布到 baode.life。

当前源码版本为 **0.8.1（build 19）**。现有公开下载记录为 0.1.0；本次项目拆分与源码同步不更新官网、安装包或版本标签。

- [产品介绍](https://writer.baode.life/) · [现有公开下载](https://github.com/cainebaode/BaodeWriter/releases/tag/v0.1.0)
- 源码：`native/`（macOS 外壳）、`web/`（本地编辑界面）
- [原生架构与验证方式](native/README.md)
- 产品官网源码：`site/`，独立部署。
- 内部项目资料的本地入口为 `docs/README.md`；内部方案、验证证据和发布操作记录单独保管。

应用在本机独立保存文稿；网站同步通过既有接口连接 baode.life，服务器接口由独立的 BaodeLife 项目维护。

## 安装与开始写作

macOS 13 或更新版本，支持 Apple Silicon 和 Intel。本地迭代安装包为 `dist/BaodeWriter-0.8.1-universal.dmg`，将「饱得写作」拖入 Applications。采用本地签名，尚未经过 Apple 公证；官网安装包另行发布。

1. 点击「＋ 新建」或 ⌘N，直接写标题和正文。看到「已保存到本机」后即可关闭；断网不影响写作。
2. 正文输入 `/` 插入标题、列表、表格或图片；也可粘贴图片。旧 Markdown 文稿保留源码编辑，可切换预览。
3. 系统菜单「文稿 → 文稿设置」中管理标签、封面、摘要和发布日期。发布日期决定网站展示；自动创建、修改时间独立记录。已发布文章地址保持不变。
4. 「连接网站」默认 `https://baode.life`，点击登录，用网站现有管理员账号登录。应用向网站确认成功后自动返回写作，侧栏显示网站域名与连接状态；再次点击可查看连接状态、读取文章或返回写作。会话失效时重新登录，断网时可继续写作。
5. 「读取网站」选择已有文章导入本机。本站图片一并下载；遇到外部图片或下载失败会显示提示，联网时可重新读取。
6. 打开单篇或勾选多篇，点击「同步到网站」，确认后文章和图片一起公开，网站自动更新。其余文稿留在本机。

「专注」隐藏整理区域；侧栏支持标题和正文搜索、标签筛选、发布日期或修改时间排序。「归档」只整理本机，不撤下网站文章。

## 文稿树与文章目录

采用已选「墨灰亚麻」配色，保留窄导航、圆角面板和暖白纸面；新建、选中文稿与 AI 入口使用暖灰陶土红。品牌标识直接使用官网矢量 Logo。系统顶部工具栏保留红黄绿，右侧并排放置哑光搜索与专注按钮；点击搜索或 ⌘F 在同一行向左展开输入框，Esc 收起并保留查询。同色背景自然衔接内容区；标签筛选位于文件列表顶部，侧栏操作与文稿标签页对齐。左侧导航的文稿按钮打开文稿树；文件列表顶部的图钉可将它固定，选择文稿后继续常驻。再次点击图钉取消固定，选择文稿或点击外围后收起。固定偏好会在下次启动时恢复。

文稿栏展开、点外部收起、选择文稿或 Esc 关闭都带有完整进出过渡；固定与取消固定时正文同步让位。目录、AI、文稿设置、菜单与弹窗沿用同一套动效，快速反向操作会从当前位置接续。Esc 优先关闭当前浮层；AI 收起后保留未发送的输入。拖动调宽直接跟随鼠标，系统减少动态效果时停用过渡。

文稿树中，每篇标题下显示博客发布日期；未发布文稿标注「待发布」与计划日期，日期与文稿设置一致。点击名称打开文稿；左侧小箭头只展开、折叠子文稿。文稿本身可以写正文，也可以拥有子文稿。行内「＋」在该文稿下新建子文稿；顶部「＋」和 ⌘N 新建顶层文稿。新建后直接输入标题。

行内「···」或右键菜单提供重命名、移动和删除。拖动时会出现跟随鼠标的标题预览和目标提示：行中部高亮表示移入，行上／下方蓝线表示插入排序，拖到拖动时出现的「移到文稿顶层」区域回到顶层。文件夹可在文件夹之间拖动排序；悬停片刻展开目标分支，靠近边缘自动滚动。Esc 或在无效位置松手取消移动；成功后新位置短暂高亮。也可用「移动到…」明确选择位置。移动父文稿时子文稿一起移动，不能移入自身或后代。已有文件夹保留为树中分组，分组下直接显示文稿。「文稿」旁的更多菜单可新建文件夹、批量选择或展开／折叠全部。

搜索覆盖标题、正文、标签与日期；命中子文稿时保留父级路径，不把结果打散。文件列表顶部的标签图标直接打开全库标签列表，点击即筛选；标签较多时可搜索标签。选中后显示标签名，点击可切换，× 只清除标签条件，不清空正文搜索。范围与排序收在「文稿 → ··· → 范围与排序」中，启用后显示可清除的提示；重置时保留所选标签。可按发布日期从新到旧、从旧到新或最近修改排序，同一分类和父子层级内排序；修改发布日期后需同步才更新网站。默认保持目录顺序，编辑正文不会使文稿跳位。文稿位置在正文上方显示，可点击父文稿返回。归档或删除父文稿不会隐藏其仍正常使用的子文稿。

系统「文稿」菜单提供文稿设置、阅读预览、移动和移到废纸篓。写作区顶部保留 AI 入口，目录从正文左边缘展开。

「目录」是当前文稿的标题大纲，与文稿树分别显示。它按照正文标题层级缩进、长标题省略、当前章节以浅亚麻色块突出；点击跳到正文对应位置。Markdown 原文定位光标，预览定位标题。目录默认收起，点击正文左边缘的小箭头展开／收起；没有额外的目录标题栏。目录与 AI 助手可以同时使用。

文稿栏通过左侧导航按钮展开／收起。固定后的文稿栏、目录和 AI 栏可以拖动边缘调宽；双击恢复默认。窄窗口进行分栏或使用 AI 时，文稿树临时改为浮层；窄窗口分栏中的目录同样由正文左边缘的小箭头打开。窗口加宽后恢复固定栏位。专注模式暂时隐藏导航与侧栏。

父子关系、文件夹随文稿备份；展开状态与栏位偏好只记在本机。整理不改变正文、网站发布内容或同步状态。

## 文稿标签与左右对照

点击列表中的文稿，会在正文上方保留一个标签；再次点击同一篇只切换到已有标签。标签固定宽度，长标题显示省略号，悬停可查看全文；打开较多时横向滚动。选中标签的标题与 × 一起包在浅陶土色圆角色块中，不使用底部装饰线。点击 × 只关闭标签，文稿仍在本机。打开的标签和分栏状态会在下次启动时恢复。

打开至少两篇后，点击标签栏右侧「分栏对照」，选择放在右侧的文稿。最多同时显示两篇，两边都可编辑、独立滚动和预览。点击哪一侧，目录、文稿设置、AI 与同步按钮就对应哪一篇；面板顶部浅亚麻色标题块标示当前编辑位置。

分栏时选择第三个标签，会替换当前操作的一侧，另一侧保持原样。「结束分栏」保留当前编辑的文稿，其他标签仍可切换。窄窗口会暂时收起整理栏，为两篇正文留出空间；退出分栏后恢复。

## 删除与恢复

打开文稿后点击系统菜单「文稿 → 移到废纸篓」，确认后移到废纸篓；也可在列表勾选多篇后一起删除。删除会关闭对应标签，其他文稿与分栏内容保留。标签上的 × 仍只关闭视图。

左下角「应用设置 → 废纸篓」可以恢复文稿，原文、图片、记录日期和文件夹归属一并保留。确实不再需要时，点击「彻底删除…」并确认，从当前本机文稿库移除正文及对应 AI 记录。废纸篓内容随文稿备份保存。

以上操作只影响本机，网站上的文章不会被删除或撤下。重新读取网站时会跳过仍在废纸篓中的文稿；需要时请先恢复。

## AI 写作助手

顶部「AI 写作」打开聊天面板。可以直接说“把这些想法写成一篇随笔”“展开第二节”“接着写”“再朴素一点”，也可先讨论观点。四个常用入口是写完整文章、重写全文、梳理结构和生成提纲；通篇优化与标题建议在更多菜单。

助手围绕当前文章工作，逐步记录你明确给出的主题、读者、立场、篇幅和语言偏好。输入框上方的「本篇写作约定」默认折叠，可随时编辑或清空；新对话保留约定，另存生成稿时带入新文稿。不必先填表，材料足够时直接写。

**讨论留在聊天，生成内容在正文区审阅。** 写整篇会生成标题与正文；修改某段、某节只替换相应范围；续写、例子或提纲可插在指定位置。查看修改对比或「新版预览」后接受，内容成为可编辑的原生标题、段落、列表等。局部修改保持其余原文与格式；Markdown 文稿继续保持 Markdown。无需复制并清理聊天说明。

选中文字后点击「AI 润色」，可直接提出修改或扩写要求。只改选区内文字，同时参考所在内容块及前后各两块；完整选中的段落可替换为多个新段落，部分选区只能文字微调或在所在块后补充。取消引用旁的 × 回到全文。独立构思从「··· → 独立构思」开始，不读取当前文稿。

上一稿还未接受时可以继续修改，助手以最新待审阅稿为依据。接受才写入正文；关闭审阅、继续追问或拒绝均不会改原文。原文有新变化时不能用旧提案覆盖。聊天中的卡片可以重新打开建议。

「··· → 修改记录与恢复」可撤销已接受的修改，或恢复为新文稿。章节替换、插入和整篇生成整体接受；文字微调可以逐处接受。图片、链接与代码遗漏会阻止覆盖，建议仍可另存或要求补齐。另存生成稿保持文档格式并保留写作约定。

在「应用设置 → AI 服务」选择服务，填写自己的 API Key 与已开通模型，保存并测试连接。支持 DeepSeek、通义千问、豆包、Kimi、智谱、MiniMax 和自定义兼容接口；模型名称可修改。密钥保存于 macOS 钥匙串，文稿备份不包含密钥；连接测试不发送文稿。

会话、写作约定与修改记录保存在本机，随内容备份保存。发送时引用内容与必要历史交给选定服务；长文或会话超限会明确提示新对话或缩小选段。助手没有联网检索和自动读取其他文稿的能力，事实材料与风格范例可在聊天中提供；生成内容仍需作者判断。未配置服务、断网或调用失败不影响本地写作。

## 同步失败或出现冲突

失败不会丢失本机文稿。恢复网络或重新登录后再次同步即可；相同文稿重复同步不会产生另一篇文章。

两端都发生变化时会显示双方版本，不自动覆盖。「采用网站版」会另存原本机内容；「保留本机版」会另存网站内容，再由你点击同步。若文章在网站被删除，先另存本机副本，按新文章发布。网站原文章的撤下与回收仍使用现有后台。

## 备份与恢复

点击左下角「应用设置 → 导出备份」，选择保存位置，得到 `.baodewriter` 文件夹，包含可读的文稿 JSON、图片和格式清单。复制整个文件夹即可备份；可再用 Finder 压缩归档。请保留整个文件夹，不单独移动其中的图片。

在「应用设置 → 帮助与恢复备份」选择备份文件夹。恢复替换当前本机文稿库，应用先保留恢复前副本；网站不会因恢复而改变。原始数据在 `~/Library/Application Support/BaodeWriter/`，自动保留上一份有效文稿文件；这不能代替独立备份。

## 从源码构建

安装 Apple Command Line Tools 和 Node.js 20 或更新版本。在本项目根目录执行：

```sh
npm ci
npm run build
```

构建依次检查类型、模型行为、前端、实际打包依赖许可证、原生存储测试，再生成 universal App 与 DMG。构建首次需要联网获取 npm 依赖和已锁定的开源源码归档。测试不会连接正式网站；原生验证命令详见 `native/README.md`。

- `web/`：写作、整理、版本冲突与手动同步界面。
- `native/`：系统窗口、本机存储、图片、登录、备份和网络桥接。
- `tests/`：正文、图片引用、日期与版本比较测试。
- `scripts/`：构建、图标、许可证归集；`package-lock.json` 固定依赖。
- `site/`：产品介绍、安装帮助、隐私说明和静态资源。网站服务端部署材料在 BaodeLife 项目归档维护。
