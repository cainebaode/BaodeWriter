本地文稿与图片

新建、编辑和整理首先保存在你的 Mac。应用不要求注册自己的账号，不内置广告、行为分析或 AI 内容上传。文件夹、归档和布局调整不会主动公开文章。

文稿库和图片保存在用户的 Application Support/BaodeWriter 目录。导出的备份由你选择保存位置；备份不包含密码或登录会话。请自行保护 Mac 账户和备份文件。

网站登录、读取与发布

应用默认连接 baode.life，可在设置中更改网站。启动、打开连接设置或登录返回时，会向当前网站检查会话状态；此检查不上传文稿或图片。你主动读取或确认同步时，才发送相应内容。登录使用网站现有登录页面，由 macOS WebKit 管理网站会话，应用不单独保存管理员密码。

读取文章时下载所选内容及可读取的本站图片。点击同步并确认后，所选文章、日期、标签和相关图片会发送到网站并公开展示。未选择的本地内容不因此上传。

网站会按自身规则处理请求和访问日志。首版的同步对象为 baode.life；外部图片或正文链接由对应服务处理，离线访问能力以应用提示为准。

产品页与 GitHub

本产品页为静态页面，没有加入统计或广告脚本。托管服务器可能保存标准访问日志。安装包、版本说明和反馈由 GitHub 提供；访问或提交 Issue 时适用 GitHub 的隐私规则，请勿在公开反馈中附带私人文稿和登录信息。

第三方组件

应用使用 BlockNote 等开源组件。具体版权声明、许可证及受 MPL 覆盖的对应源码随安装包提供，位于应用包 Contents/Resources/licenses/；也可在 版本下载页 单独获取第三方许可包。应用自有源码已在 GitHub 公开，构建方法与许可边界见仓库说明；第三方组件继续遵循各自许可证。
