A LITTLE HELP

开始写作，
也安心保管文字。

适用于 0.1.0 · 更新于 2026-10-25

安装与第一次打开

  1. 从本产品页或 GitHub Releases 下载 DMG，打开后将「饱得写作」拖入「应用程序」。
  2. 当前预览版采用本地签名，尚未经过 Apple 公证。macOS 可能阻止首次打开，请先确认下载来源与 SHA-256 校验一致。
  3. 如决定继续使用，请按 Apple 官方安装说明，在尝试启动后到「系统设置 → 隐私与安全性」查看该应用的提示，并自行确认是否打开。无需关闭系统的整体安全保护。

要求 macOS 13 或更新版本。安装包包含 Apple Silicon 和 Intel 架构；本轮实际运行验证使用 Apple Silicon，Intel 已完成编译与架构检查。

写下第一篇

点击「＋」或按 ⌘N 新建。标题与正文直接编辑；正文输入 / 可插入标题、列表、表格和图片。内容自动保存在本机，看到「已保存到本机」即可关闭。⌘S 也可立即保存。

旧 Markdown 文章保留原文编辑，并可切换预览；不会自动转换成其他正文格式。图片优先使用本机文件，网站导入时会尝试保存本站图片，外链或失败资源会单独提示。

文件夹、标签和目录

文章列表左侧管理文件夹，抓住文章左侧手柄可拖入文件夹，也可勾选多篇后批量移动。删除文件夹只会把文章移到未分类。标签在文稿设置里管理，点击左侧标签查看同类文章。

右侧目录自动显示正文各级标题，点击可跳转，章节可以折叠。拖动分隔线调宽，双击恢复默认宽度；顶部「布局」可恢复隐藏的栏，专注模式暂时收起所有侧栏。

记录日期与修改时间

设置里的「记录 / 展示日期」由你决定，用于日期排序与网站展示。自动记录的创建时间和修改时间独立保存。

连接与同步网站

首版同步仅对接 baode.life，需要该站管理员权限。本地写作不要求登录；暂不支持任意博客或其他内容平台。

  1. 在「连接网站」打开网站现有管理员登录。成功验证后显示「网站已连接」。
  2. 点击「读取网站」，选择已有文章导入。本站图片会一起下载；网络失败或外部图片会提示。
  3. 打开单篇或勾选多篇，点击「同步到网站」，核对并确认。文章和图片一起公开，其余文稿仍留在本机。

同步失败时保留本机内容，恢复网络或登录后可重试。同一文稿重复同步不会新建另一篇。两端都有修改时保留双方版本，由你选择；不会静默覆盖。归档只影响本机，不撤下网站文章。

导出、恢复与更新

点击「导出备份」，保存为 .baodewriter 文件夹，内含原始文稿、图片和格式清单。请复制整个文件夹；可用 Finder 压缩后保存到其他磁盘。

在「帮助 → 恢复备份」选择完整备份文件夹。恢复前会保留当前库的安全副本，恢复不会改变网站。备份不包含登录信息。自动保留上一份有效文稿文件不能代替独立备份。

更新前退出应用，用新版覆盖「应用程序」里的旧版本。文稿存放在用户的 Application Support/BaodeWriter 目录，与应用包分开。暂不提供自动更新。

反馈问题

请在 GitHub Issues 或通过 邮件 联系作者，附应用版本、macOS 版本、复现步骤和错误提示。不要发送密码、完整备份或私人文章。
